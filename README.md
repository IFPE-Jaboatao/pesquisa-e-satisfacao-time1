# pesquisa-e-satisfacao-time1

Sistema desenvolvido para realizar pesquisas de satisfação e coletar opiniões dos usuários


---


## Funcionalidades

    -Cadastro de usuário
    -Criação de pesquisas
    -Cadastro de perguntas
    -Avaliação de satisfação
    -Registro de respostas
    -Gerenciamento de dados


-----
    

## Tecnologias Utilizadas

    Node.js
    TypeScript
    NestJS
    PostgreSQL


-----


## Instalação do Projeto

Clone o repositório:

```bash
 git clone https://github.com/IFPE-Jaboatao/pesquisa-e-satisfacao-time1.git
 ```

    Entre na pasta do projeto:

```bash
 cd pesquisa-e-satisfacao-time1
 ```


  -----


## Instalação das Dependências


```bash
npm install
```


-----


## Execução do Projeto

Modo desenvolvimento:


```bash
npm run start:dev
```

Modo produção:

```bash
npm start
```


-----
